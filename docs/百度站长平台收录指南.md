# MindForge 官网 · 百度站长平台收录指南

> 目标：让百度能搜到 MindForge 官网。
> 代码侧（Sitemap、验证标签注入、自动推送脚本、CI）已经全部就位，
> 你只需要按本文在百度站长平台点几下 + 配两个 GitHub Secret。

---

## 零、先说一个重要前提（建议看完再动手）

官网目前挂在 `opok-ops.github.io/MindForge/`。客观情况是：

- 百度对 `github.io` 这类境外免费托管域名的**抓取频率和权重都偏低**，收录慢、不稳定；
- 这不是配置能解决的，是域名本身的问题。

所以分两种预期：

| 你的诉求 | 建议 |
|---|---|
| 只是希望"百度上能搜到 MindForge" | 按本文做即可，通常几周内会收录，但排名和稳定性不保证 |
| 希望稳定收录、有正常搜索排名 | **强烈建议绑定一个自己的域名**（几十块一年的 `.cn` / `.com`），再按本文操作，效果差距很大 |

如果你决定绑域名，流程是：买域名 → 仓库 `Settings → Pages → Custom domain` 填域名 → 域名解析加一条 CNAME 指向 `opok-ops.github.io` → 再按本文操作。

> 注意：国内服务器托管域名需要 ICP 备案，但 GitHub Pages 属于境外托管，**不需要备案**。

## 一、添加站点

1. 打开 [百度搜索资源平台](https://ziyuan.baidu.com/)（原"百度站长平台"），用百度账号登录
2. 左上角 **添加网站** → 用户中心 → 站点管理 → 添加网站
3. 网址填（**必须完全一致，包括结尾的斜杠**）：

   ```
   https://opok-ops.github.io/MindForge/
   ```

   ⚠️ 这是后续所有报错的头号原因。`/MindForge/` 这个子路径和结尾的 `/` 都不能少。

4. 填完会进入「验证站点」步骤，先别急着验证，继续看第二步

---

## 二、验证站点所有权（推荐用 HTML 标签方式）

百度给三种验证方式，**推荐第 2 种**（我们已经预留好自动化）：

### 方式 A：HTML 标签验证 ✅ 推荐

1. 在验证页面选择 **「HTML标签验证」**
2. 百度会给一段代码，长这样：

   ```html
   <meta name="baidu-site-verification" content="code-xxxxxxxxxx" />
   ```

3. **只复制 `content` 里那一串值**（形如 `code-xxxxxxxxxx`）
4. 打开 GitHub 仓库 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   - Name：`BAIDU_SITE_VERIFICATION`
   - Value：刚复制的那串值
5. **触发一次部署**，让验证码真正上线（这步不能跳，否则验证必然失败）：
   - 最简单：仓库 → `Actions` → `Deploy Website to GitHub Pages` → `Run workflow`
6. 等约 1 分钟部署完成，打开 https://opok-ops.github.io/MindForge/ ，右键「查看网页源代码」，搜索 `baidu-site-verification`，能看到你那串值说明注入成功
7. 回到百度站长平台点 **验证**

> 原理：`website/index.html` 里预留了 `<!--BAIDU_VERIFY_SLOT-->` 占位符，
> CI 检测到 `BAIDU_SITE_VERIFICATION` 这个 Secret 就会自动替换成真实的 meta 标签。
> 没配 Secret 时它保持为注释，不影响页面。

### 方式 B：文件验证

百度会给你一个 `baidu_verify_xxxxxxxxxx.html` 文件，把它放进 `website/` 目录后 push 即可。适合不想配 Secret 的情况。

## 三、提交 Sitemap

站点验证通过后：

1. 左侧 **资源提交 → Sitemap**
2. 填入：

   ```
   https://opok-ops.github.io/MindForge/sitemap.xml
   ```

3. 提交

Sitemap 已按百度规范整理过：

- 只收录首页。官网是单页站点，`#quickstart`、`#hybrid` 这些锚点**不产生独立页面**，列进去是无效重复条目，已移除；
- `demo.html` 设置了 `noindex`，按规范不出现在 Sitemap 中；
- `lastmod` 由 CI 每次部署自动更新为当天，不用手工维护。

## 四、配置 API 主动推送（自动，一次配好长期生效）

这是**收录最快**的方式，比等蜘蛛自己来快得多。

1. 左侧 **资源提交 → API 提交**
2. 复制「推送接口」里的 **token**（接口地址里 `token=` 后面那一串）
3. 仓库 `Settings → Secrets and variables → Actions → New repository secret`
   - Name：`BAIDU_PUSH_TOKEN`
   - Value：刚才复制的 token
4. 完成。之后每次官网部署完成，`.github/workflows/baidu-push.yml` 会自动推送。
   也可以随时手动跑：仓库 → `Actions` → `百度站长平台 - 主动推送` → `Run workflow`

### 本地手动推送

```bash
# 用环境变量传 token（推荐，不落盘）
export BAIDU_PUSH_TOKEN=你的token
python scripts/baidu_push.py

# 或者只看看会推什么，不真正提交
python scripts/baidu_push.py --dry-run
```

脚本仅用 Python 标准库，无需安装任何依赖。

## 五、验证效果

| 检查项 | 位置 | 预期 |
|---|---|---|
| 推送是否成功 | `Actions` → `百度站长平台 - 主动推送` 的日志 | 出现 `推送成功：本轮提交 1 条` |
| 百度是否抓到 | 站长平台 → 抓取诊断 | 填首页 URL，抓取成功且能看到 meta 标签 |
| 是否已收录 | 百度搜索框输入 `site:opok-ops.github.io/MindForge` | 有结果即已收录 |

## 六、常见问题

**Q：推送报 `HTTP 400：site init fail`**
A：站点还没在站长平台添加成功，或 `site` 与登记的网址不一致。核对尾斜杠和 `/MindForge/` 子路径。

**Q：推送报 `HTTP 401：token is not valid`**
A：token 复制错了，或者复制成了「站点验证码」——这两个不是同一个东西。token 在 **资源提交 → API 提交** 页面。

**Q：验证一直失败**
A：90% 是因为没触发部署，meta 标签还没上线。按第二步第 5 点手动跑一次部署，等 1 分钟再验证。

**Q：推送成功但很久没收录**
A：正常。主动推送只是"告诉百度这里有页面"，最终是否收录由百度决定。`github.io` 域名通常会慢一些，这也是建议绑自己域名的原因。

**Q：CI 里显示黄色警告"未配置 BAIDU_PUSH_TOKEN"**
A：正常，不是错误。没配 token 时工作流会跳过推送，不影响官网部署。
